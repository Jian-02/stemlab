🎵 음원 분리 도구

mp3 / mp4 파일을 업로드하면 악기별 트랙으로 분리해 드립니다 (Demucs 기반, 로컬 실행).

새 작업

※ 6-스템 모드의 피아노(및 기타) 분리는 Demucs 모델 자체의 한계로 정확도가 낮을 수 있습니다 (학습 데이터 부족). 일반 4악기(보컬/드럼/베이스/그 외) 품질을 높이고 싶다면 "4-스템 고품질" 옵션을 사용해 보세요.
※ "백코러스/하모니 분리" 모드는 반주가 섞여 있으면 안 되고, 이미 보컬만 분리된 파일을 넣어야 합니다. 아래 작업 목록에서 완료된 보컬 스템 옆의 "백코러스/하모니 분리" 버튼을 누르면 다시 업로드하지 않고도 바로 추가로 나눌 수 있어요. 리드 보컬과 백코러스가 같은 목소리라 반주 분리보다 어려운 작업이라, 곡에 따라 결과 품질 차이가 클 수 있습니다.
※ "보컬 멜로디 악보로 만들기"는 자동 채보(AI가 음을 듣고 악보로 옮기는 것)라 완벽하지 않습니다. 비브라토나 빠른 구간, 랩처럼 말하듯 부르는 부분은 음정/박자가 틀릴 수 있어요. 결과는 "초안"으로 보고 직접 다듬는 걸 추천합니다. 마찬가지로 완료된 보컬 스템 옆의 "🎼 악보로 만들기" 버튼으로 바로 만들 수 있고, 화음이 있는 피아노/기타 반주에는 잘 안 맞습니다. (설치 시 주의: requirements-transcribe.txt로 먼저 설치한 다음, basic-pitch는 "pip install --no-deps basic-pitch"로 따로 설치해야 합니다 — 그냥 설치하면 다른 기능과 충돌나는 tensorflow까지 같이 딸려옵니다. 자세한 설명은 requirements.txt 주석 참고.)
